# 後年入力の公式資料補完計画

モデル・試行・読み出しの凍結は変更しない。対象は原データの品質監査と別コピーへの補完であり、PostgreSQLや本番データを書き換えない。

## 判明した事実

- 重複24組は、保存した元レコードの版・日付・同一馬名から解消した。原版と置換台帳を保存済み。
- 続く公式頭数チェックでは36レースが不一致。35レースは2026-01-03／08-08／08-29の出馬版のままで、実際には開催済み。残る2025-11-01帯広7R馬番4は公式に出走取消。
- 公式PDF3本（47／48／48ページ）を原本保存し、macOS PDFKitで全文抽出した。HTMLの古い成績表にはない全馬の単勝オッズもPDFに存在する。
- 不一致の全350 SEレコードは342件が版2、8件が版7。313馬IDに対して、取得できたUMは同名別IDを含め84件。97出走行はIDに対応するUMが存在し、馬名・年齢と生年の不一致はゼロ。UMだけでは残る253出走行を検証できなかった。その後、同じ313馬IDの確定版SE履歴（2020年〜2026-09-06）を追加照合し、全350出走行で馬名・生年・品種の一致を確認した。未照合・矛盾はともにゼロ。ただし参照履歴には対象レースより後の記録も含み、当時の入手可能性や公式サイトの別形式IDとの対応を証明するものではない。

## 実装前の確認順序

1. 原本SE／RA／UMとハッシュを保存し、同じIDの確定版SE履歴から馬名・生年・品種を照合する。馬名だけから登録番号を生成・置換しない。矛盾や同定不能なものは停止する。
2. PDFの各レースを独立に抽出する。12レースのヘッダー、全馬番・馬名、公式実出走頭数を検証する。PDF文字列では数字が分割・重複している場合があるため、推測的な読み飛ばしを禁止する。
3. 着順、明示的な出走取消・競走除外・競走中止、全馬の単勝オッズを抽出する。着順のない行も残す。未知の状態語はエラーにする。
4. オッズ列と馬の対応を検証する。抽出順だけに依存した対応は、人数・馬番・馬名・公式HTMLの成績／人気／利用可能なオッズと突き合わせる。曖昧ならPDF座標情報に戻る。
5. 決定的な単体テストを追加し、通常、取消、除外、競走中止、同着、10頭の分割表記、不完全・重複・曖昧入力を検証する。既存のlint／型／coverageを通す。
6. 同定済みの完全なロスターにのみ、公式結果を別コピーとして適用する。変更前後・根拠URL・PDFハッシュ・対象列を台帳化する。取消は公式状態から判断し、競走中止馬は実出走馬として保持する。
7. 元の厳格な `export_starter_history` を変更せずに再実行する。完全頭数・未知の通常着順・重複の検査を全部通す。歴史文脈にも同じ補完を適用し、レース日が予測日より前という条件を維持する。
8. 完全な入力を監査した後でのみ、固定済み5ケース×4条件を評価する。データ取得で見た結果から再選択・再調整しない。

## 完了記録

上記の検査・補完と、その後の固定比較を完了した。原版・失敗時の監査・各訂正版を保持し、ID、版区分、作成日を結果に合わせて書き換えていない。

- 対象側：6,280レース・60,669出走、着順未定義の実出走377件。公式中止46レースを照合。現在の対象価格の不備はゼロ。
- 全履歴側：543,643 SE／53,611 RAの原版を抽出し、44件の版置換と公式補完を適用。追加の文脈専用15レースは、全178ロスター行の馬名・年齢・性別を照合した。174行は確定履歴、残る4行はJVD馬マスターで確認した。
- 川崎2026-01-03のアートオブライフは公式PDFの競走除外を根拠に扱い、取消・失格・競走中止も明示的に区別した。
- native履歴の最終出力：53,216レース・534,170出走、performance rating未定義2,168件。通常記録の説明不能な着順欠損7件はいずれも2020年以前で、既存の検査条件は変更していない。
- 対象60,669出走は全履歴と全列・双方向で完全一致。追加15レースと対象種レースの交差はゼロ。
- 履歴だけの87件の欠損価格は推測補完せず保持した。scalar文脈には過去のperformance ratingを使い、その過去価格は使わない。
- NARのみJRA由来23,194履歴を追加。13,813レースの公式JVD頭数で補正し、同一馬・物理レースのnative優先を結果・価格とは独立に適用した。ばんえいへの混入はない。
- 12セルが `load_validation_data` を通過。予測日は2024-01-01〜2026-09-06、文脈は各予測日の厳密な過去だけを使う。
- モデル・入力ハッシュの事前確認後、5ケース×4条件を実行。全20条件が「通算1着増加かつ年別2〜5着非悪化」の採用条件を満たさなかった。[結果詳細](later-frozen-readout-results.md)参照。追加学習・設定変更・本番置換はゼロ。

主要成果物は `.cache/chronos2/cell-improvement/nar-banei-validation-inputs/` の `full-history-export-manifest.json`、`full-history-extra-overlay-ledger.json`、`full-starter-history.parquet`、`jra-transfer-manifest.json`、`history-manifest.json`、`combined-history-audit.json` と各公式資料・補完台帳。

## 解釈上の制限

これは後年入力の品質問題であって、2023年の学習効果を説明する証拠ではない。公開PDFは翌日作成等の事後資料であり、訂正後の記録を使用しても当時のas-of入手可能性を証明できない。独立ホールドアウト・PIT・本番採用の主張には使わない。
