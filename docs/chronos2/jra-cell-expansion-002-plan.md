# JRA改善セル拡大：第2段階の実験計画

## 目的と成功の定義

ユーザーの追加指示に基づき、JRAを優先して改善セル数を増やす。前回は6セル中3セルが開発基準を通ったが、後年の採用条件を通ったセルは0だった。この数字を起点とし、MAE改善・市場への上乗せ・未調整モデルへの上乗せを分けて数える。改善は目標であり、結果を保証しない。

主指標は1〜5着の完全一致。市場比1着増加と年別2〜5着非悪化を緩和しない。既存候補の不採用決定を変更せず、新実験は別の名前空間で保存する。現行モデル・PIT・本番実行条件の承認は引き続き別問題で、本番は変更しない。

## 実装前の調査

1. 既存JRA96試行をセル別に再整理する。元の設定、対象レース数、学習ラベル数、最低履歴数別の予測可能率、MAE、各順位一致、未調整差、市場差を突き合わせる。
2. 未改善を「順位を変えられない混合」「変わるが誤る」「1着改善と他順位悪化」「対象外ラベル中心の更新」に分解する。最後の項目は介入前には原因確定としない。
3. canonicalセルの2020〜2023年の件数と手元の履歴対応率を監査する。既存6セルに加えて候補を最大12セルへ広げられるか調べる。追加候補は2023年の完全ソース件数とセルIDだけで順序付け、成績の良いセルを後付けで選ばない。件数がないセルや未整備セルも記録する。
4. 既存予測を使う読み出し診断と、実際に重みを更新する実験を区別する。後年の結果を重み・表現・候補選択に入力しない。

## 最初の因果比較：文脈を残して教師だけを限定

- `run_study` は現在、domain/prefixで教師を制限するが、対象セルのrace IDでは制限しない。文脈行を削らず、明示的な教師レース集合を適用できる機構を追加する。
- 旧動作は既定値として完全に保持し、対象外レースを過去文脈として使えること、同日・未来を使わないこと、空の教師集合で停止することをテストする。
- 同じ初期化・seed・更新数・文脈長・最低履歴数・バッチ設定で、従来教師とセル内教師を比較する。未調整対照も同じ予測対象・混合方法で評価する。教師選択による効果と学習率変更を混同しない。
- まず件数順で選ぶ未改善セルを優先した小規模パイロットとし、2 seedの対応比較を行う。最大2セル×2教師条件×2 seed＝8回の学習を第一予算上限とする。セル・設定・seed・評価方法はデータ監査後、学習前に別JSONで固定する。元の96試行のモデルを変更しない。
- ラベルは2020〜2022年、評価は2023年、過去文脈は2000年以降の厳密な過去。2023年も既に観測した開発集合であり、独立検証とは呼ばない。

## 次の介入を選ぶ条件

セル限定教師だけで改善しない場合、単純な再探索を繰り返さず、順位目的の損失または読み出しを一要因ずつ比較する。順位損失はレース単位バッチと完全ロスターが必要で、現在の馬単位pinball学習に無検証で追加しない。特徴追加はその後の別介入とする。

後年2024〜2026年を新設定の探索には使用しない。新候補を開発結果で固定した後だけ、既観測年での追加検証として比較する。失敗後に設定を救済せず、全対象セル・全試行・両seedの結果を残す。

## 実行・資源・品質

- 最新の作業場所指示を優先する。cwdは `/Users/kkk4oru/ghq/github.com/kkkaoru/horse-racing-data`、新規成果物は `research/chronos2/`、一時ファイルは同配下の `runtime/scratch/` に限定する。`.cache`・`.local`・`/tmp`への新規書き込みとworktree作成は禁止。既存資産は削除・変更せず、必要な入力としてのみ参照する。
- 既存Python環境を `bash research/chronos2/run-local.sh <command>` から利用する。このラッパーはcwd、TMPDIR/TMP/TEMP、ライブラリの保存先を通常のリポジトリ内ディレクトリへ固定する。旧launcherは `.cache` に書くため、この段階では使わない。TF32無効、CPU4スレッド、外部モデル取得はoffline、重い処理は同時に1本。
- 一時領域へログを作るtmux実行ツールは以後使わない。長時間処理が必要な場合も、ログ・PID・終了状態を `research/chronos2/` 配下へ明示して実行する。指示前に完了していた初回監査結果は `research/chronos2/jra-expansion-002/` にコピー済み。
- 現在の空き容量は約17 GiB。学習開始前に保存容量を見積もり、既存288モデル・4対照・公式原資料は削除しない。新規成果物の可逆圧縮は既存のハッシュ照合済み方式に限る。容量が不足するなら拡大を止める。
- 新しい教師マスク、データ境界、評価ロジックに対応テストを追加。既存の閾値・測定範囲を変更せず、Ruff、設定を明示したbasedpyright、Chronos範囲ty、全テストとcoverageを通す。
- 第1段階の成功数だけで実験を終えず、改善しないセルの内訳を次の介入選択に使う。ただし、後年成績を見た再調整や本番反映は行わない。
